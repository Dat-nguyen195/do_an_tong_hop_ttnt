\section{CONCLUSION}\label{sec:conclusion}
This project preserves the supplied SEMSYNTH architecture and implements a limited executable subset: candidate adapters, bounded probes, binary partition entropy, hard filtering, and explicit stopping states. The learned 47-feature mapping, atomic/diversity machinery, AGA, scalable hierarchy, and adaptive regeneration remain part of the design and future integration work.

On 32 controlled synthetic cases, Balanced passes every retained test in 32 cases versus 13 for each noninteractive selector, using 1.4688 questions per case. Two saved eight-case LLM-labeled pilots show 8/8 passing selections versus 7/8 and 6/8 respectively. These finite-suite results establish the observed behavior of selection with a noiseless reference oracle and the available pools. They leave candidate-generation coverage, general correctness, noisy feedback, scalability, and human effort open. The source and evidence package supports replay of the measured selection outcomes and a clean rebuild of this report.
