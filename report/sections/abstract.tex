\begin{abstract}
Ambiguous natural-language specifications admit several plausible programs. SEMSYNTH addresses this problem through semantic clarification, information gain, Bayesian belief revision, and hypothesis management. This course project preserves the full architectural design while implementing a small subset: candidate generation adapters, bounded execution probes, binary output questions, and hard filtering. We explain how binary partition entropy follows from the original information-gain objective under uniform priors and deterministic observations. On 32 controlled synthetic cases from eight related template families, the first-candidate and first-valid selectors each pass all retained evaluation tests on 13 cases (40.625\%), while balanced clarification passes on 32 cases, using 1.4688 questions per case. Saved pilot artifacts for two model identifiers each contain eight synthetic tasks; balanced selection passes all retained tests on both pilots, versus seven and six passing tasks for the respective noninteractive selectors. Feedback comes from a noiseless reference-program oracle. The 15-task HumanEval/MBPP-derived pilot catalog is audited separately and is not the measured benchmark. The results support selection behavior within these saved pools; they do not establish general program correctness, human effort reduction, noisy-feedback robustness, or large-scale performance. Source, saved pools, verification logs, and LaTeX files accompany the report.
\end{abstract}
